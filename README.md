# 동위각·엇각 스피드 퀴즈

중학교 수학에서 동위각과 엇각을 복습하기 위한 모바일 대응 웹 활동입니다.

## 현재 구현
- 학생 번호·이름 입력
- 일반 게임 60초 / 관리자 테스트 30초
- 동위각, 엇각, 평행선에서 각의 크기 문제 자동 출제
- 정답 +1점, 오답 -2점
- 오답 후 3초 입력 제한
- 관리자 비밀번호 4550
- 반응형 PC·스마트폰 화면

## GitHub Pages
Repository의 Settings → Pages에서 `main` 브랜치와 `/ (root)`를 선택하면 정적 웹사이트로 배포할 수 있습니다.

## 랭킹 DB 연결
현재 `firebase-config.js`는 설정 템플릿입니다. 여러 학생 기기에서 실제 랭킹을 공유하려면 Firebase 프로젝트와 Firestore를 연결해야 합니다. Firebase 설정값을 넣은 뒤 Firestore 보안 규칙을 함께 구성해야 합니다.

관리자 비밀번호가 프런트엔드 코드에 포함되는 방식은 교실 활동용 간단한 접근 제한일 뿐 보안 인증 방식은 아닙니다. 실제 운영에서는 Firebase Authentication 또는 서버 측 관리자 인증을 권장합니다.
